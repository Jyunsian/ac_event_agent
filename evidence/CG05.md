## Criteria

### C1 — 完整客戶交付

- 優先候選與完整 Validation Family 共享同一 catalog/detail source；每列包含 Category、indicator、observation start/end、decision time、trigger mode、D2／D3／D7、membership、coverage、evidence status 與 detail hash。

- candidate API／export／read tools 接受 V3 schema，仍驗證 report version、dataset、candidate identity 與 detail checksum。

### C2 — 72h 最小互動圖

- `candidate_value_map_v3.json` 直接投影 validation D3 checkpoints，不在前端重算；逐候選測試比對 X、Y、status 與 detail hash。
- 僅 `decision_time_hours <= 72` 且 X／Y 皆有值者標成 `PLOTTED`；late／null 狀態的 schema model 會拒絕錯誤畫點。
- 全部圓點使用單一 accent、相同半徑；顏色與大小不承載其他數值。Category filter、hover、click、鍵盤 Enter、焦點與可及性數據表通過實際瀏覽器驗證。

### C3 — 不重算、離線與 Agent 引用

- 離線 HTML CSP 固定 `connect-src 'none'`，所有圖、表、detail 與 Discovery log 均從已封裝 artifact 載入；無外部網路依賴。
- React report model 對 V3 執行 schema、有限數值、identity 與 plotted safety 驗證；Agent read-back 返回精確 detail hash，不以 summary 替代 detail。
- 介面沿用既有 Linear 風格雙欄、dark token 與結果資訊架構；設計檢查落實單一 accent、相同點大小、鍵盤焦點、reduced motion、桌面／手機無頁面水平 overflow，未新增儀表板式多圖。
