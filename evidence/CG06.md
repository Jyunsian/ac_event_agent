## 收尾修正

- V3 search 使用 indexed bitset membership、精確 Pareto 與增量 diversity；Validation diagnostics 分批，避免 2,000 候選同時展開造成 OOM。
- finding recheck 依來源 immutable config 的 `analysis_version` 路由；V3 finding 重驗在 API 前置明確拒絕，不再排入必敗 Worker 任務。
- V3 follow-up 沿用可恢復 StageRunner，保留 parent run／branch provenance。
- V3 segment 新增 cohort-only 診斷；回傳 exploration／holdout 真實人數與收益可用性，標示 exploratory 且不冒充候選層重驗。
- 6-user 驗收資料若不足三個通過 sample filter 的候選，Agent 引用 summary 說明無法比較，不降低門檻或虛構候選。
