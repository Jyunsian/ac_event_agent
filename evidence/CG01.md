## Criteria

### C1 — Schema、AST 與非法輸入

- JSON Schema 限制 V3 analysis version、20,000/2,000/10 上限、bootstrap=1,000、兩原子 boolean、預註冊兩步 sequence、有限 gap/repeats 與 artifact hashes。
- Python semantic contract 拒絕 Category mismatch、非 snapshot 的 `lte`、錯 denominator、錯 sequence constraints、24h gap 套錯模板、非有限數值與 candidate ID mismatch。
- `contracts/check.py` 同時驗證 22 個既有案例與 7 個 V3 案例。

### C2 — 獨立手算真值

- `tests/fixtures/casual_v3/expected.json` 明示人工枚舉，未由 production 函式生成。
- fixture 固定 `[24,48)`、`[48,72)`、`[72,96)` 的右端歸屬、合法 retry/start-complete pair、同時間無 source sequence 不配對、缺 `level_index` 與 terminal conflict。
- schema inventory test 核對 4 users、15 events 及人工邊界值。

### C3 — Identity、相容與保留

- `candidate_id` 對 canonical JSON 穩定，變更 observation end 會換 identity。
- V3 baseline request 持久保存 `calculation_version=3.0-casual-game` 與 config analysis version。
- 現有 IAA ingest／fixture tests 與 upload API 回歸通過；來源 SHA 在 canonicalize 前後保持一致。
