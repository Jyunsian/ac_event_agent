# 產品語言改造對照

本文件記錄已實作的顯示層調整。L01–L05交付門檻已通過，最後回歸、真模型抽樣及已知限制見 LANGUAGE_AUDIT.md 與 evidence/LANGUAGE-L05.md；不是所有模型回覆永遠正確的保證。

| 原本的呈現 | 現在的呈現 | 使用者得到什麼 |
|---|---|---|
| 基礎報告已發布 | 目前還不能選出值得優先測試的事件／找到有歷史資料支持的事件條件 | 先知道結果是否值得繼續研究，而不只是處理完成 |
| D7 ARPU | 前 7 天平均廣告收益，附美元單位 | 知道比較什麼收入與時間範圍 |
| 候選 ID／事件 JSON | 安裝或首次開啟後幾小時內，累積幾次指定行為 | 不用先讀程式設定就能理解事件條件 |
| 成熟／未成熟用戶 | 已有完整 7 天資料／還未完整觀察 7 天 | 知道哪些人能納入收益比較，未完成觀察不補零 |
| 門檻敏感度 | 提高要求，還有多少人符合？ | 明白圖表回答的問題，而不必理解統計分類名稱 |
| Jaccard | 同時符合兩個條件的人數，除以至少符合其中一個的人數 | 保留正確分母，不誤認為以所有人為分母 |
| 分群結果 JSON | 分群事件比較表，分開呈現尋找條件與檢查結果的人群 | 直接比較條件、人數、收益與達標時間 |
| 重新整理分支 | 重新整理結果清單 | 明白是在找既有結果，不會啟動重新分析 |
| HTML／CSV／JSON 三個格式名稱 | 同時說明直接閱讀、試算表、程式使用的用途 | 知道應下載哪一種檔案 |
| 固定舊規則重驗 | 之前找到的事件，這次仍適用嗎？ | 與尋找新事件區分，知道本次不會改門檻 |
| 技術錯誤碼作主訊息 | 先說無法顯示的內容、可保留閱讀的結果與下一步；細節可展開 | 不要求一般使用者修復執行環境 |

## 不能因白話化而改變的意思

Agent 已實作的改寫：

- 原本直接列出 `report:…`，現在以「查看證據」按鈕表示；找不到可核對來源時，顯示「這項引用的來源尚無法確認」，不猜測版本。
- 原本整段 Markdown 當文字顯示，現在呈現標題、段落、清單與比較表；工程程式內容與原文可以展開。
- 原本告知使用者設定 OpenRouter 或修復任務服務，現在告知「分析助理暫時無法使用，既有報告仍可閱讀」。
- 原本顯示「建立探索分支」，現在顯示「安排另一組條件的分析」，不把排入背景分析說成結果已完成。
- 回覆規範要求先回答問題，再給關鍵發現、必要限制與一個下一步；純讀報告不應重算。此規範已寫入 prompt，真模型的遵循程度另列驗收，不以文字規範當成行為證明。

- 收益高是歷史觀察，不是投放改善的保證。
- 用來找條件的人群與留出來檢查的人群不同，不混用分母。
- 缺值是未知；非常小但非零的收益不可顯示成零。
- 報告中的精確值、來源、事件設定與版本仍可查閱；原始檔與已發布報告不覆寫。
- 當檢查資料已被閱讀，再改條件得到的是新發現，不能冒稱同一批資料再次提供獨立驗證。
