## 語言與資訊層級

1. 主內容回答：要提供什麼、現在發生什麼、結果代表什麼、下一步是什麼。
2. 補充說明解釋分母、時間定義、歷史比較與樣本限制。不能因隱藏術語而隱藏結論限制。
3. 技術詳情保留原始 ID、hash、工具、錯誤碼、規格、精確值；原始資料与已發布報告不覆寫。

| 內部詞 | 主要顯示 |
|---|---|
| D7 ARPU | 前 7 天平均每位用戶的廣告收益 |
| mature | 已完整觀察 7 天的用戶 |
| coverage | 符合條件的用戶比例 |
| trigger | 符合事件條件 |
| branch | 另一組條件的分析（顯示具體条件與時間） |
| sensitivity | 調整條件後的變化 |
| exploratory | 仍需用新資料確認 |
| holdout | 留出來檢查結果的用戶 |

缺值顯示「未知」，不顯示零；時間採易讀小時／天，精確值可查；金額必須帶美元單位，小額不可四捨五入到看似零。狀態 unknown 不得映射為通過。未知錯誤提供安全的通用說明，不直接顯示原始伺服器文字。不得宣稱所有失敗都能重試或所有資料都已保存。

Agent：直接回答 → 關鍵發現 → 本次必要限制 → 一個有價值的下一步。不在正文堆內部代碼；引用由可信資料綁定成友善標籤；不得自由注入 HTML。新候選組合與只改時間是不同實驗，不作因果歸因。模型不可用不影響既有報告。

## 共同交付門檻

- 逐階段留下 evidence/LANGUAGE-Lxx.md，實際命令、結果、失敗及修復都保留。
- 舊測試中硬編碼的術語 locator 可改為新的可讀名稱，但原功能斷言不可刪減。
- UI 文案／Markdown 安全單測、Python HTML 數值與規格對照、既有上傳與對話整合測試，最後真瀏覽器桌面及手機人工檢視。
- 真模型僅用本專案有效授權憑證及合成資料；沒有有效憑證則記 EXTERNAL_CHECKS，不阻塞本地測試，不冒充真模型通過。
- 完成時提供改寫對照、可操作本機 URL、測試步驟與外部延期。逐項審核後才關閉 Goal。
